workflow

番茄工作法
流程一览

01

设定专注时长

按 [C] 进入设置菜单，[A] 切换时长选项（5秒测试 / 5~60分钟），[B] 跳转下一设置项，[C] 保存并返回。

BtnC · 设置
02

开始 / 暂停 / 恢复

主界面按 [A] 一键开始计时；专注中再按暂停，暂停中再按恢复，累计暂停时间精确计入偏移量。

BtnA · 控制
03

语音命令（长按 A）

长按 [A] 激活麦克风录音，说出「开始二十五分钟」或「start 25 minutes」，百度 ASR 识别后自动启动对应时长。也可说「停止」终止当前计时。

BtnA Hold · 语音
04

休息 & 循环

每完成 1 次专注自动进入短休（5 分钟），每 4 次专注触发长休（15 分钟），百度 TTS 语音播报当前状态，闭眼休息也不会错过提醒。

自动 · 循环
05

查看本周统计

按 [B] 切换至统计图界面，七天柱状图清晰呈现当日进度，今日列黄色高亮。任意按键或触摸返回。

BtnB · 统计

语音识别流程

长按 BtnA → 麦克风录音（最长5秒）
静音 800ms 自动停止录音
PCM 16kHz → 百度 ASR API
解析 JSON → 提取分钟数
百度 TTS 播报确认语音
WiFi 离线 → 节奏蜂鸣 fallback
hardware

M5Stack Core2
全栈整合

📱

2.0" IPS 触摸屏

320×240 全彩显示，电容触摸支持点击返回，高亮度适合桌面使用。

🎙

内置 PDM 麦克风

16kHz 单声道录音，配合 RMS 静音检测，5 秒内完成语音采样。

🔊

内置扬声器

PCM 16kHz 直推播放 TTS 语音，音量可软件调节，无需外接音频设备。

📡

ESP32 双核 + WiFi

240MHz 双核，内置 WiFi 连接百度 AI Cloud，PSRAM 提供 5 秒录音缓冲。

💾

NVS Flash 持久化

使用 Preferences 库将设置与统计写入 Flash，掉电数据不丢失。
