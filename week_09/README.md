# 🍅 StackPals - Core2 虚拟形象番茄钟基础版

本项目基于 M5Stack Core2 硬件，实现了一个带有表情反馈的桌面番茄钟工具。当用户进行专注或休息时，屏幕上的虚拟形象会做出相应的表情变化（如严肃、开心、困倦），并通过内置喇叭提供蜂鸣提醒。

## 🛠️ 准备工作：配置开发环境 (必看)

如果你是第一次烧录这个项目，请**严格按照以下步骤**配置环境，否则大概率会报错！

### 1. 安装软件
1. 下载并安装 [Visual Studio Code (VS Code)](https://code.visualstudio.com/)。
2. 在 VS Code 左侧的扩展市场（快捷键 `Ctrl+Shift+X`）中，搜索并安装 **PlatformIO IDE** 插件（图标是一个外星人头像）。
3. 安装完成后，VS Code 右下角会提示正在安装核心组件，请耐心等待它安装完毕并提示重启 VS Code。

### 2. 打开项目的正确姿势 (极其重要！！！)
千万不要直接用 VS Code 打开外层的父文件夹！
**一定要确保用 VS Code 打开的是包含 `platformio.ini` 文件的这个目录。**
- **操作方法**：点击 VS Code 左上角的 `文件` -> `打开文件夹...`，选中本项目所在的文件夹（确保进去第一层就能看到 `platformio.ini` 和 `src` 文件夹）。
- **成功标志**：打开后，VS Code **最底部的状态栏**会出现一排 PlatformIO 的快捷图标（一个打勾 `✓` 和一个向右的箭头 `→`）。如果没有出现，说明你打开的层级不对。

## 🚀 编译与烧录步骤

1. **连接设备**：用 Type-C 数据线将 M5Stack Core2 连接到电脑。
2. **选择编译环境**：
   - 看 VS Code 最底部状态栏，找到 `Default (xxxx)` 字样并点击。
   - 在顶部弹出的列表中，**务必选择 `env:m5stack-core2`**。
3. **下载依赖 (自动)**：
   - PlatformIO 会在后台自动下载 `M5Unified` 和 `Avatar` 等底层库。你可以留意右下角是否有 `Downloading...` 的提示。请等待它下载完成，代码里的红色波浪线会自动消失。
4. **一键烧录**：
   - 点击 VS Code 底部状态栏上 **向右的箭头 `→` (Upload)**。
   - 底部终端会开始滚屏编译。第一次编译可能需要几分钟，请耐心等待。
   - 当终端最后出现绿色的 **`[SUCCESS]`** 字样时，说明烧录成功，Core2 会自动重启并亮屏！

## 🎮 如何使用

程序启动后，屏幕会显示一张中立的脸庞，底部有三个隐形的触摸感应区（对应 A、B、C 三个按键位置）：

- **👉 按下左下角 (BtnA) - 开始专注**：
  - 机器人表情变为 **生气/严肃**。
  - 开始工作倒计时（目前测试版为 10 秒，需在代码中修改为 25 分钟）。
- **👉 按下正下方 (BtnB) - 开始休息**：
  - 机器人表情变为 **开心**。
  - 开始休息倒计时（测试版为 5 秒）。
- **👉 按下右下角 (BtnC) - 随时重置**：
  - 随时打断当前状态，表情恢复正常。

> **🔔 提示音**：按键时会有短促“滴”声，倒计时结束时会有长鸣警报，同时表情变为“闭眼困倦”。
